# Styled Portfolio Website

## Overview
This is a styled portfolio website created using HTML and CSS. The website showcases my introduction, skills, projects, and contact information in a clean and responsive design.

The purpose of this project was to practice and improve my frontend web development skills while building a professional portfolio website.

## Features
- Responsive website design
- Navigation bar
- About Me section
- Skills section
- Projects section
- Contact form
- Hover effects and styling
- Mobile-friendly layout using media queries

## Technologies Used
- HTML5
- CSS3

## CSS Concepts Used
During this project, I learned and implemented:

- CSS selectors:
  - Element selectors
  - Class selectors
  - ID selectors
  - Pseudo-classes

- CSS properties:
  - Color
  - Background
  - Font
  - Border
  - Margin
  - Padding

- Box Model:
  - Content
  - Padding
  - Border
  - Margin

- Responsive Design:
  - Media Queries

## Purpose of the Project
This project helped me understand:
- How to style web pages using CSS
- How to create responsive layouts
- How to structure a portfolio website
- How to improve webpage design and user experience
